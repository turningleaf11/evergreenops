Buy Box

The internal screening rule — what auto-fails a deal, what's merely a preference, and which exceptions are real. This is what Cash screens against before an underwriter spends any time. The public page at buybox.evergreenreventures.com is the outward version; this is the decision logic behind it.

How screening works

The distinction that matters operationally, and the one the public page doesn't carry.

Hard

Fails the screen outright. Stop, report which criterion failed, don't underwrite. Unless an exception applies.

Soft

A target, not a gate. Missing it is noted and carried forward — never fatal on its own.

Widened band

The threshold is simply relaxed for this case. Note it and proceed.

Conditional adjustment

Curable, not waivable. State the condition, price the cure into the model, flag for a human. Never auto-waive.

The buy box is the filter, not the verdict. It runs before underwriting to decide whether a deal is worth modelling at all. The tools' own thresholds — DSCR 1.25, cash-on-cash 7%, IRR 12%, $100/door — are the verdict, applied after the model runs. Confusing the two is how a deal that should have died in sixty seconds consumes an afternoon.

Exceptions

Documented exceptions, so a rule bent for good reason is distinguishable from a rule quietly ignored. Type determines how it's handled.

Widened bandAll asset classes · geography
Out-of-market deals considered when the case is compelling

Condition — the property, operator, or deal structure makes a compelling case.

Human sign-off — required.

Conditional adjustmentFix & flip · beds
Under 3 beds is acceptable if a bedroom can be added

Condition — sqft and layout are large enough to sustain an additional bedroom.

Adjustment — add the conversion cost to the repair budget, then re-run the model.

Human sign-off — required. Feasibility is never assumed.

Widened bandFix & flip · ARV
Will consider lower fills with strong comps

Condition — comps supporting the lower ARV are strong.

Human sign-off — required.

Widened bandMultifamily · units
4–9 unit properties still get a look despite the 10-unit floor

Condition — unit count falls between 4 and 9.

Human sign-off — not required.

Known gaps

  • OpenCo-living / PadSplit has no criteriaAn exit strategy the team hasn't modelled yet, so it's deliberately absent rather than guessed at.
  • OpenBusiness acquisitions have no criteriaThe asset class exists in the schema; the buy box for it doesn't.
  • OpenNo screen has been run yetunderwriting_runs is empty. These rules are structured but unexercised — the first real screens are what will show whether the thresholds are right.
