Modern SaaS aesthetic inspired by Linear/Notion/Vercel. Key principles:

- **Surfaces**: Neutral base, clear contrast between page background and cards. No accent-tinted sidebar.
- **Radius**: `rounded-2xl` cards, `rounded-xl` buttons/inputs/badges
- **Shadows**: Multi-layer soft shadows with inset top highlights on cards. Hover increases shadow, no transform.
- **Typography**: `font-bold` headings, clear hierarchy (page-title 2xl, section-title base)
- **Spacing**: Generous — `p-8` page padding, `space-y-10` sections
- **Colors**: Neutral palette. Accent only for primary actions, status, and active indicators. Badges use soft `bg-primary/10`.
- **Header**: Glass effect with `backdrop-blur-sm` and `bg-card/80`
- **Nav active**: Left 2.5px accent bar + `bg-primary/8` pill
- **Dark mode**: Deep backgrounds (224 24% 4%), card at 7%, stronger border visibility
- Crystal mode removed entirely.
