

# Feed Social Upgrade, Market Research Enhancements, Forms Relocation

## Phase 1: Feed → Social Media Feel

### 1A. Move Feed to Main Sidebar Nav
- Remove the "Intranet" collapsible group from `AppSidebar.tsx`
- Add "Feed" as a top-level nav item (Megaphone icon) in `mainNav` array
- Remove "Forms" from sidebar entirely

### 1B. Add "Post" Type (Anyone Can Post)
- **Migration**: Create `posts` table (id, author_id, author_name, content text, image_url text nullable, gif_url text nullable, created_at)
- **RLS**: Any authenticated user can create; all can view; authors can edit/delete
- Update `CompanyFeedPage.tsx` to fetch posts alongside announcements/polls/kudos
- Update `FeedCard.tsx` with a new `PostCard` component

### 1C. Social Composer UI
- Replace the current dialog-based creation with an inline composer at top of feed (like Facebook/LinkedIn)
- Show user avatar + "What's on your mind?" textarea
- Media toolbar: Image upload button (to `files` bucket), GIF search button (inline Giphy-style search using Lovable AI to avoid needing a Giphy API key — or a simple curated set)
- Post type selector only visible to admins (Announcement, Poll) — regular users just see the compose box for posts and kudos
- Image preview before posting

### 1D. Post Cards with Social Feel
- Each card shows: author avatar + name, timestamp ("2h ago"), content, optional image/GIF
- Reaction bar (emoji picker) and reply thread already exist — keep those
- Add image rendering in cards (full-width, rounded corners)

## Phase 2: Market Research Enhancements

### 2A. Custom Strategy Text Box
- Add a `Textarea` field to `MarketResearchPage.tsx`: "Describe your strategy, criteria, and what you're looking for"
- Pass this custom text to the edge function alongside the strategy dropdown
- Update `supabase/functions/market-research/index.ts` to include user's custom criteria in the AI prompt

### 2B. Sources Disclosure
- Add a `sources_note` field to the AI tool-calling schema in the edge function — instruct the AI to list what types of data/knowledge it drew from
- Display a "Sources & Methodology" collapsible section at the bottom of each analysis card
- Add a disclaimer: "Analysis generated by AI based on publicly available market data and trends. Not financial advice."

### 2C. Save Custom Criteria
- **Migration**: Add `custom_criteria` text column to `market_research` table
- Save the user's typed criteria with each research record so they can reference what they asked for

## Phase 3: Forms Relocation

### 3A. Remove Forms from Sidebar
- Already handled in Phase 1A

### 3B. Admin Form Management
- Add a "Forms" tab in `SettingsPage.tsx` (or keep the existing `/forms` route but only link it from Settings)
- Admin can create/edit form templates and review submissions here

### 3C. User Form Access
- Add a "Forms & Requests" section on the Home page — shows available form templates as cards
- Add a "Submit Form" quick action in Department hub dropdowns
- Users can view their own submission history from the Home page section

## Phase 4: Feed Post with Images

### 4A. Image Upload in Posts
- Use existing `files` bucket for uploaded images
- On compose, clicking the image button opens file picker → uploads to `files/feed/{uuid}` → stores public URL in `image_url`
- Display uploaded images in post cards with proper aspect ratio

### 4B. GIF Support (Simple)
- Add a small curated GIF search using Lovable AI (edge function that returns GIF URLs from its knowledge) — or integrate Giphy's free API if preferred
- For MVP: allow pasting a GIF URL directly, render it inline
